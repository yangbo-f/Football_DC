# Dixon-Coles 足球预测需求草案

## 1. 目标

建立一个比较精确、可回测、可解释的足球比赛预测模型。第一阶段优先预测赛前概率，而不是赛中实时概率。

核心输出：

- 具体比分概率，例如 `1-0`, `1-1`, `2-1`
- 胜平负概率
- 大小球概率，例如 `Over/Under 2.5`
- 双方进球概率 BTTS

## 2. 第一版边界

第一版使用历史比分数据和手动输入赔率：

- 赛事
- 赛季
- 比赛日期
- 主队
- 客队
- 主队进球
- 客队进球
- 是否中立场
- 十进制赔率

暂不加入：

- 球员伤停
- 首发阵容
- xG
- 天气
- 赛程密度
- 联赛之间强度换算

这些可以作为第二阶段增强特征。

## 3. 模型选择

使用 Dixon-Coles 模型作为第一版主模型，因为它比普通独立泊松模型更适合足球低比分场景。

模型包含：

- 每支球队的进攻参数
- 每支球队的防守参数
- 全局主场优势
- 低比分相关修正参数 `rho`
- 时间衰减权重，让近期比赛更重要

## 4. 数据要求

最低数据量建议：

- 单一联赛至少 1 个完整赛季
- 更推荐 2-4 个赛季
- 球队名称必须标准化
- 比赛日期不能缺失
- 只使用预测日前已经发生的比赛

比赛 CSV 字段：

```csv
competition,season,date,home_team,away_team,home_goals,away_goals,neutral_site
```

赔率输入字段：

```csv
market,selection,line,odds_decimal,bookmaker,captured_at
```

## 5. 评估方式

不要只看命中率。推荐：

- Log loss：概率预测最核心指标
- Brier score：胜平负概率校准
- Ranked probability score：适合胜平负这种有序结果
- 校准曲线：检查 60% 概率的事件是否真的约 60% 发生
- 回测收益：如果未来接入赔率，再单独评估

## 6. 回测规则

为了避免数据泄漏：

1. 按日期排序比赛。
2. 对每个预测日，只用该日期之前的比赛训练。
3. 预测当天或未来比赛。
4. 记录预测概率和真实结果。
5. 汇总评估指标。

## 7. 已确认的第一版需求

1. 赛事范围：英超 + 世界杯。
2. 训练方式：按赛事分开训练，不把俱乐部联赛和国家队赛事混在一个模型里。
3. 预测市场：胜平负、比分、大小球、BTTS、亚洲让球、欧洲让球。
4. 数据方案：免费 CSV + 手动上传补充；第一版不接付费 API。
5. 使用方式：本地网页手动预测。
6. 赔率用途：做价值对比和赔率融合概率，不改基础 Dixon-Coles 训练参数。

## 8. 下一阶段增强

可按收益逐步加入：

- 滚动回测脚本
- 球队升降级和跨赛季衔接处理
- 赔率隐含概率
- xG 替代真实进球训练
- 赛程密度和休息天数
- 伤停和首发
- 分联赛参数或层级贝叶斯结构
- 每日自动批量赛程和赔率更新

## 9. 当前数据与赔率口径

- 基础模型数据完全来自加载的比赛 CSV。
- 训练按 `competition` 分开，例如 `WorldCup`、`EPL`、`CSL`。
- 世界杯、中超、英超文件建议放在各自目录下，由 catalog 统一管理。
- 点球大战和晋级信息只做展示，不写入 `home_goals/away_goals`。
- 赔率支持手动输入和 CSV 导入；自动 API 预留接口，暂不抓取网页。
- 页面展示纯模型概率、人工修正概率和赔率融合概率，避免混淆来源。
